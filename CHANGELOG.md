# Changelog

## 1.0.0

- Initial standalone release of `cli-anything-openwebui`.
- Provides OpenWebUI server, auth, chat, RAG, model, file, user, admin, memories, prompts, notes, automations, generic API, config, session, and REPL commands.
- Includes JSON/YAML output, saved profiles, optional keyring token storage, and local undo/redo for harness session state.
